## Known Limitations

- Root `.env.example` is empty (documentation gap).
- Dev CORS default is `http://localhost:3000`; local RC UI uses port **3010**.
- Worker has no strict single-instance lock — run exactly one worker.
- Localhost defaults remain for API rewrite and some secrets fallbacks in non-production.
- README still describes an older “V1.0 MVP” start path.
- Workspace package.json versions are not all `0.9.0-rc.1`.
- LLM script JSON may occasionally fail schema validation (`AGENT_INVALID_OUTPUT`); one limited official retry succeeded on this RC. Do not retry unbounded.

P0: 0. P1: 0. These P2/P3 items do not block Local Windows Web RC.
